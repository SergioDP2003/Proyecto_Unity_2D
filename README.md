## Introducción
Este proyecto consiste en el desarrollo de un videojuego 2D inspirado en *Don Quijote de la Mancha*, centrado en la dualidad entre la realidad y la imaginación del protagonista.  
El jugador acompaña a Don Quijote y a Sancho Panza en una serie de aventuras donde los elementos del entorno pueden percibirse de manera diferente según el punto de vista del caballero andante.

El juego combina narrativa, pequeños escenarios, diálogos y combates por turnos, ofreciendo una experiencia interactiva que mezcla acción y relato.

> **IMPORTANTE**  
> Para poder jugar al juego, únicamente es necesario acceder a la carpeta **Juego_Exe** y ejecutar el archivo  
> **Proyecto_Unity_2D.exe**.

---

## Motivación
La motivación principal de este proyecto es trasladar una obra literaria clásica al formato de videojuego, explorando cómo los elementos narrativos pueden integrarse en una experiencia interactiva.  

Además, el proyecto sirve como una primera toma de contacto con el motor **Unity** y el lenguaje de programación **C#**, ya que ambos eran nuevos para los desarrolladores del juego. El objetivo ha sido aprender las bases del desarrollo de videojuegos mediante la práctica.

---

## Contenido
El repositorio incluye:
- Escenas 2D con distintos entornos del juego.
- Sistema de diálogos entre personajes.
- Sistema de combate por turnos.
- Gestión de enemigos, estadísticas y movimientos.
- Scripts en C# que controlan la lógica del juego.
- Ejecutable para probar el juego sin necesidad de Unity.

---

## Problemas
Durante el desarrollo se han presentado diversos desafíos, principalmente derivados de la inexperiencia inicial con Unity y C#.

Al comienzo del proyecto surgieron bastantes dificultades con la interfaz de Unity, ya que resultaba confusa y poco clara. Sin embargo, con el paso del tiempo se demostró que es una herramienta bastante intuitiva y basada en el sentido común.

En el desarrollo de los escenarios también aparecieron problemas relacionados con la creación de superficies mediante **tilesets**, especialmente pequeños errores visuales y desajustes de píxeles.

Por último, el uso de **GitHub** supuso otro reto, ya que al trabajar en equipo y subir el código a distintas ramas surgieron conflictos en determinados archivos que debieron resolverse manualmente.

Todos estos problemas han servido como aprendizaje y han ayudado al equipo a comprender mejor el flujo de trabajo en Unity, C# y el uso de GitHub para el desarrollo colaborativo.

## Futuro
Entre las posibles mejoras y ampliaciones futuras se encuentran:
- Añadir más aventuras y escenarios (como el castillo).
- Mejorar el sistema de combate con habilidades especiales.
- Incorporar sonido y música más dinámica.
- Optimizar el sistema de diálogos con animaciones y efectos visuales.
- Implementar un sistema de guardado de partida.
- Mejorar la interfaz y la experiencia de usuario en general.

---

## Conclusión
Con este trabajo se ha realizado una aproximación sólida al uso de Unity mediante la creación de un videojuego en un periodo de tiempo reducido.  
Aunque el aspecto visual del juego no alcanza un nivel profesional, cumple con los objetivos planteados y permite al equipo sentirse satisfecho con el resultado final.

El proyecto ha permitido experimentar de primera mano el proceso de creación de un videojuego, sentando una base de conocimientos que podrá ampliarse y mejorarse en futuros desarrollos.



El trabajo realizado sienta una base sólida para futuras mejoras y demuestra el potencial del videojuego como medio para reinterpretar obras literarias.
